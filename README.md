# 📄 PaperMate

AI research assistant. Search, download, read, chat with papers.

## Features
- 🔍 4 free sources: PubMed, Europe PMC, OpenAlex, arXiv
- 📥 Smart downloads with Unpaywall
- 💬 Local AI chat (Ollama)
- 📚 Zotero sync
- 📝 Citations

## Audit: 100% pass

## Quick Start
pip install -r requirements.txt
ollama pull llama3.2
python run.py
